Drop exported WAV one-shots here (any sample rate, mono/stereo). They replace the synth stand-ins by FILENAME keyword:
kick* | snare*/clap* | hat*/top* | cowbell* | bell* | growl*/grwl* | yah*/vox* | pow*/thud*/thunk*/impact*/boom*
Pitched files named like `Harmor 808 Cowbell 2_G#3_127.wav` have their root note parsed, so the hook repitches correctly.
Kicks are layered with the synth sub-kick so the low end stays intact.
